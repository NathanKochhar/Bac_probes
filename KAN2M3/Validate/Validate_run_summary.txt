CHANGES TO BAC-PROBES MADE FOR THIS RUN
---------------------------------------
1. Strains count as the target species (always on)
   SILVA labels many sequences with a strain or subspecies ("Helicobacter
   pylori 26695", "Campylobacter jejuni subsp. doylei"). bac-probes used to
   match species names exactly, so these counted as OFF-target. A species
   target now matches any SILVA name that starts with it followed by a space
   (find, coverage, cocktail, validate and BLAST classification).
   Effect here: all 178 exact off-targets in the first run were strains or
   subspecies of the target itself; now every probe has 0. Target totals
   (first run -> now):
      Fusobacterium nucleatum      30 ->    137
      Helicobacter pylori         200 ->    338
      Prevotella jejuni             5 ->      5
      Escherichia coli          4,007 ->  5,267
      Cutibacterium acnes          47 ->     79
      Campylobacter jejuni        246 ->    356
      Enterobacter hormaechei     123 ->    271

2. Unnamed congeners (new option --exclude-unnamed-congeners)
   Many BLAST off-targets were "uncultured bacterium". That is SILVA's
   placeholder for environmental sequences with no species name. When such
   a sequence sits in the target's own SILVA genus (e.g. "Cutibacterium;
   uncultured bacterium" for a C. acnes probe), it may well be the target
   species, so it isn't necessarily a real off-target. Unnamed sequences in
   OTHER genera, and named sister species, are real off-targets and still
   count.
   With the option, validate keeps the standard columns and adds
   *_excl_unnamed columns with those same-genus unnamed hits set aside.
   Neither number is exact: the standard value is the worst case, the
   excl_unnamed value the best case.
   Probes where this changes BLAST wspec by >= 0.05:
      Fusobacterium nucleatum #1: 0.463 -> 0.959
      Fusobacterium nucleatum #2: 0.907 -> 0.988
      Fusobacterium nucleatum #3: 0.438 -> 0.849
      Fusobacterium nucleatum #5: 0.286 -> 0.633
      Escherichia coli #1: 0.636 -> 0.713
      Cutibacterium acnes #2: 0.327 -> 0.956
      Cutibacterium acnes #3: 0.167 -> 0.914
      Cutibacterium acnes #5: 0.828 -> 0.998
   These are mostly C. acnes and F. nucleatum probes: SILVA has 1,585
   unnamed Cutibacterium and 850 unnamed Fusobacterium sequences. For
   H. pylori, C. jejuni and E. hormaechei the change is small, so their
   remaining off-targets are real (named species or other genera).


COLUMNS USED BELOW
------------------
  exact cov      = target sequences containing the probe exactly (either strand)
  exact off      = non-target sequences containing it exactly
  BLAST tgt      = target sequences BLAST aligns to the probe at >= 85%
                   identity (near-matches; a rough upper bound on what could
                   bind), with % of the species' sequences
  unnamed congener hits = BLAST off-target hits in the target's genus with
                   no species name
  BLAST wspec    = blast_weighted_specificity: off-target near-matches weighted
                   by mismatch position (central mismatches ~ won't bind, end
                   mismatches ~ may bind). Weighting window = 40 bp.
  excl. unnamed  = blast_weighted_specificity_excl_unnamed
Pooled coverage per species can't be computed from validate's output (it
doesn't report which sequences each probe hits), so it isn't given here.
