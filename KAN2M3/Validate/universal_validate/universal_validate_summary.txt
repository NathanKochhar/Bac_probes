=================================================
Run: bac-probes 0.1.0, 2026-10-05
Input: universal_bacteria_validate.csv (13 probes, 32-40 bp, taxa Bacteria, level domain)
Database: SILVA 138.1 SSURef NR99 (510,508 sequences) + SILVA BLAST database
Target: domain Bacteria (431,575 sequences). Off-targets: Archaea (20,389) and

Command:
  bac-probes validate silva_db/SILVA_138.1_SSURef_NR99_tax_silva_full_align_trunc.fasta.gz KAN2M3/Validate/universal_validate/universal_bacteria_validate.csv --blast --blast-max-target-seqs 500000 --breakdown phylum --min-seqs 500 --threads 14 --output KAN2M3/Validate/universal_validate/validation_results.tsv

  --blast-max-target-seqs 500000: must exceed the 431,575 bacterial sequences,
  or BLAST stops before reaching off-target near-matches.
  --breakdown phylum: coverage per bacterial phylum (phyla with >= 500 seqs).


HEADLINE
--------
  - Highly specific: every probe has BLAST weighted specificity >= 0.99999,
    and there is only 1 exact off-target match in total (probe 1, one
    Metazoa sequence). No probe hit the BLAST hit cap.
  - Not universal: together the 13 probes exactly match 17.7% of bacterial
    sequences (76,344 / 431,575). Individually they match 0-10%.
  - Several probes start on a universal 16S site (probe 1 begins with the 515F
    primer sequence GCAGCCGCGGTAATAC; probe 13 sits in the V3 region) but, at
    32-40 bp, extend into variable regions shared only by some groups. Several
    match mainly Enterobacteriaceae-like sequences.

WHAT THIS MEANS
---------------
  - As a universal set these probes would miss most bacteria, including
    essentially all Bacteroidota, Campylobacterota and Fusobacteriota.
  - Exact coverage is a strict measure; the higher BLAST near-match numbers
    (up to ~81% for probe 1) show many more sequences differ by only a few
    bases. Whether those bind depends on where the mismatches fall, so the
    real coverage is somewhere between the exact and near-match figures.
  - For comparison, the universal set designed with bac-probes design
    (KAN2M3/Bacteria) reaches 95.3% exact coverage with 15 probes at similar
    specificity.


CAVEATS
-------
  - SILVA classifies chloroplasts (5,049 sequences) and some mitochondria
    (1,188) as Bacteria, so binding to organelle rRNA counts as coverage here,
    not off-target.
  - Large-subunit rRNA (23S/28S) is not in this database, so binding to it is
    not checked. Coverage and specificity are measured against SILVA 138.1 only.
